# Rachel Zeng Real Estate

Static React + Vite SPA for a luxury real estate website, optimized for Vercel deployment.

## Local development

```bash
bun install
bun run dev
```

## Production build

```bash
bun run build
```

This project uses:

- React + Vite
- TypeScript
- TanStack Router
- Tailwind CSS
- Static client-side routing with SPA rewrites on Vercel
